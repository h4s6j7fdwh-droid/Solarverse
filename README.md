# SolarVerse 3D Solar System Explorer

เว็บไซต์จำลองระบบสุริยะ 3D สำหรับเผยแพร่ด้วย GitHub Pages

## วิธีใช้งานบน GitHub Pages

1. สร้าง repository ชื่อ `USERNAME.github.io`
2. อัปโหลดไฟล์ `index.html` จากชุดนี้ไปไว้ที่ root ของ repository
3. ไปที่ **Settings → Pages**
4. ที่ **Build and deployment → Source** เลือก **Deploy from a branch**
5. เลือก branch ที่ใช้ (เช่น `main`) และโฟลเดอร์ `/ (root)`
6. กด Save แล้วรอการเผยแพร่เว็บไซต์

จากนั้นเว็บไซต์จะอยู่ที่:

`https://USERNAME.github.io/`

> หมายเหตุ: ไฟล์ต้นฉบับถูกนำมาใช้เป็น `index.html` โดยตรง เพื่อรักษาการทำงานของ SolarVerse ตามต้นฉบับ
